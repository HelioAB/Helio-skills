### T1 冷启动 + 收敛终止

- 开场：`/grill-x 我想开始健身`
- 考察：
  - 一句话模糊输入下初始 design tree 的搭建；首轮是否一次问出整个 frontier。
  - 块格式是否严格照模板：Q 编号、`---` 分隔、My recommendation、a–d 选项、收尾问句引用字母。
  - 依赖后置的问题（训练计划细节依赖目标/场地）是否留到后续轮。
  - 一路答到底：是否正确判定 frontier 已空、总结共识并等用户确认，而非无限拖轮或提前收场。
- 结论：**通过——冷启动建树、分轮纪律、收敛终止全部符合；余两处小瑕疵，其一复现 T4 已记录的 P3。**（2026-10-14，transcript `3309fa67-b887-46f4-9906-cfdf2da5ea1a`，JSONL 判读；skill 仍为 v1，修复未实施）
  - 冷启动与首轮 frontier：开场 Glob `*` 与健身关键词扫描确认零相关文件（asst#37/38），轮首声明"从零开始"；首轮一次问出全部 6 个根决策（目标/场地/时间/基础/范围/交付物），互相独立，无下游问题混入。
  - 块格式：15 块（3 轮 14 问 + 1 共识确认块）全部照模板——Q 编号、`---`、My recommendation+理由、(d) 你的方案收尾、背景段仅事实题/价格事实出现且克制。瑕疵：字母作答提示只在 R1/R2 轮首出现，R3 与确认轮均缺（模板要求收尾问句引用字母）；用户实际仍以裸字母作答，无功能损害。
  - 依赖后置：R2 四问（采购/日程口径/数据口径/评估）全由 R1 答案解锁；R3 四问中两问由 R2 答案新派生（"只买哑铃+弹力带"→哑铃类型、无凳→家中替代支撑物），两问是口径已定缺值（三天时段、四项数据）——frontier 随答案真实重塑。
  - 收敛终止：R3 后正确判定"边界清空"（asst#83），共识表+推导骨架后以标准问题块求确认，等用户答 `a` 才动手——不提前收场、不拖轮。唯一未给值（晚间具体时点）显式留白，未默默默认。
  - 无推荐泄漏：用户三次选在推荐项对立面（居家、固定哑铃、极简采购），最终计划完全建在用户选择上——固定三阶哑铃无小重量跳档，据此推导"组数→次数→节奏"双递进与 15kg 达标后采购 20kg 的升级线。
  - 交付位置自相矛盾（复现 P3 且有加重）：R1 Q6 选项 (a) 与共识表格均写"放当前目录"，骨架段与确认块却写 `fitness/`，实际写入自创 `fitness/` 子目录（asst#95/99）。与 T4 P3 同根因（写入位置无规则依据）；加重表现是共识摘要表格与骨架自相矛盾——用户确认的是骨架版本，同意链条存在但不干净。归入既有 P3，随 D1 定案一并解决。
  - 交付物归属干净：plan.md/log.md 是 R1 Q6 用户自选的交付形态，且开场 Glob 显示目录内无兄弟话题文件——排除 T4 P2 式模仿。
  - 计划外副作用：向沙盒项目 memory 写入 `fitness-12week-program.md` 并编辑 MEMORY.md（asst#103/116）。skill 无此指令，属 harness 记忆行为，不判 skill 违规，记录在案。
  - 全程观察项：通过。无 emoji；旧格式漂移零出现（❓/➡️ 全文 0 次）。

- 开场：`/grill-x 我打算两周后搬到另一个城市生活`
- 考察：

  - 每轮答案是否真正重塑 frontier：如用户选"城市已定"后，解锁的问题集应与"帮我选城市"完全不同。
- 结论：**中止（未完成）——仅首轮可判，根级提问与依赖后置通过；本测核心项"答案重塑 frontier"未及验证，需重测。**（2026-10-14，transcript `c8dfbb72-7456-4d7e-8edd-2768168e66e3`，JSONL 判读）

  - 依赖后置（通过）：轮首显式建树——根节点下六主枝（驱动力、目的地锁定、收入、同行者、现居处置、承诺级别），落脚方式/物流/行政手续/倒排表显式声明留待后续轮；块内推理引用跨问题依赖（Q2 未定城则本周优先级变为定城、Q6 承诺级别随 Q1 驱动力而定），六问互相独立，未提前问任何下游问题。
  - 格式：六块合规，收尾问句规范引用字母（"直接按 `Q1: a / Q2: b / …` 回答即可"），比 T1 更贴模板字面；Q4 标注可多选并给 `Q4: a+d` 示例，处理得当。两处偏离示例形（不判违规）：4/6 块枚举四实项、开放项落到 (e)，符合"开放项字母随序列"规则但超出 a–d 示例；My recommendation 写作"(a) 工作机会驱动"自带字母前缀，示例无此写法。
